# knowledge-center

Hub de documentación viva de modelos de ML — dashboard + Model Cards computados en vivo desde los
repos de proyecto, sin base de datos ni almacenamiento propio ("vista computada"). POC en la
cuenta personal `luxitoppsai` que simula el sistema real de documentación MLOps de un COE de
modelos.
